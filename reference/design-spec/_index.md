# 設計文書の参照知識

設計文書 (DR / プロトコル / 仕様) を書く・直す・レビューするときの確認項目。2 つの入口がある。**これから書く / 決めていく**なら着手前チェックを、**一通り書けた / 指摘対応が一巡した**なら仕上げチェックを読む。書き方の思想 (目的の立て方、責務から問う) は `for-all/rules/design-thinking.md` が正本。

## 着手前に固める

- [spec-preflight](spec-preflight.md) — スコープの粒度、前提条件と不成立時の併記、実装裁量を残す箇所の区別、曖昧な数値の禁止、やらないことの書き方と不採用表、やらないことを守るテスト。
  発火語: DR を書く, 仕様を決める, プロトコル設計, スコープの粒度, 前提条件, 推奨値, 不採用表, やらないこと

## 仕上げに確認する

- [spec-finishing](spec-finishing.md) — 通読、目的確定前の記述の疑い、相互参照の機械検証、廃止言及の削除、章立てと分量、削って良くなるかの試し、作業上の注意。
  発火語: 設計文書のレビュー, 節番号の参照, §参照が壊れる, 設計文書の通読, 章立て, 旧案への言及, 版を残す
