# `say` に渡す頭字語のカタカナ変換

| 元 | 渡す文字列 |
|---|---|
| OTP | オーティーピー |
| URL | ユーアールエル |
| API | エーピーアイ |
| CI | シーアイ |
| PR | ピーアール |
| 1Password | ワンパスワード |
| jj | ジェイジェイ |

- 対象は頭字語・略語 (各文字を順に読むもの) のみ。普通の英単語 (`hello`, `error`, `failed` 等) は say が正しく読めるのでそのままで良い
- 判断に迷う固有名詞 (プロダクト名、ツール名) はカタカナ化を優先 (誤読リスク回避)
- 文中の日本語と混在してよい。カタカナ化が必要なのは頭字語の部分だけ (例: `say "シーアイ が failed しました"`)
