# 行長を揃えるための改行をしない

markdown を出力する全ての場面 (rule / skill / docs のファイル、チャット応答、SendMessage / ccmsg 等のエージェント間メッセージ、commit / PR 本文) で、1 行の文字数を意識した改行をしない。特に **文の途中で改行しない**。

- 折り返しはビュー側に任せる。文中改行はプレビューエンジンやチャット UI によってはそのまま見えて読みづらいだけ
- 改行は段落・箇条書き・表・コードブロックの構造にだけ使う
- 既存ファイルの hard-wrap は触ったついでに直す (一括 reflow はしない)
