# 覚えておくべき事実の書き先

事実を記憶に残すと判断したら、書き先を先に決める:

- **そのプロジェクトでしか意味を持たない** → そのプロジェクトの auto-memory
- **別プロジェクトのセッションが読んでも効く** (kawaz の好み、ツール横断の運用、環境の癖) → プロジェクト横断メモリ (手順は `knowledge` skill の「メモリ」節)
- **feedback** (kawaz の指摘・好み・確認済みのやり方) は原則**横断側**。特定リポの事情に閉じると判断できる場合だけ auto-memory
- **rule / skill に書いた (昇格させた) 事実は memory に残さない**。rule が正本で全セッションに載るので、memory 側は二重記録になり古くなるだけ

## Why

横断側に置くべき事実を auto-memory に書くと、そのプロジェクトのセッションでしか思い出せず、同じ指摘を別プロジェクトで繰り返させる。
