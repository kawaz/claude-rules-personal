# 覚えておくべき事実の書き先

事実を残すと判断したら、書き先を先に決める:

- **そのプロジェクトでしか意味を持たない** → そのプロジェクトの auto-memory
- **別プロジェクトでも効くが rule にするほど一般化していない** (環境の癖、ツール横断の運用、確認済みのやり方) → `knowledge` skill のローカル層 (`${CLAUDE_PLUGIN_DATA}/`)
- **個人情報系** (本人の表記、アカウント名、連絡先) → `knowledge` skill の private 層 (privacy リポ)
- **公開してよい体系知識** → `knowledge` skill の `reference/`
- **全セッションで毎ターン効く行動制約** → rule。rule / reference に昇格させた事実は上の各層から消す (正本の二重化を避ける)

## Why

横断で効く事実を auto-memory に書くと、そのプロジェクトのセッションでしか思い出せず、同じ指摘を別プロジェクトで繰り返させる。層を混ぜると public リポに個人情報が漏れる / 一般化前のメモが git に積もる。
