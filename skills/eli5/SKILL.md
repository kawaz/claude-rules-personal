# eli5

このトピックを何も知らない人向けに、**大きな図と少ない言葉**の HTML アーティファクトで説明して。
日本語は大人向けの普通の文体で、漢字も普通に使う (ひらがなだらけにしない)。専門用語は避けるか、
出す時は図で意味が分かるようにする。

- 図は inline SVG (ライト / ダーク両対応)、外部画像・外部 CSS は使わない
- 1 画面 1 メッセージのスライド風 (縦スクロール)。各枚は大きな図 + 1〜2 文。文章の壁を作らない
- 書く前に `artifact-design` と `artifact-diagramming` の skill を読む。publish できない環境
  (claude.ai ログイン無し) なら HTML ファイルを渡し、置き場はユーザに従う
- 業務固有名詞・ローカルの絶対パス・秘密情報を入れない
