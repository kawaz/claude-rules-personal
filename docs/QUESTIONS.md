# 裁定・確認待ち一覧 (ユーザ用)

## 運用規約

<details>
<summary>ゼロコンテキストエージェント向け（本セクションは消さない）</summary>

- 裁定/確認待ち項目を 1項目=1ラベル=1セクション で記載
- ラベル形式: `XX-Q1` の `XX` は **2-3 文字**。雰囲気で分かる程度でよく、意味が
  なくてもよい。Qn 単独の使い回し禁止、長期一意性は不要
- 依頼形式: 「👺XX-Q1 の裁定お願いします」（参照用途ではラベルに👺を付けない。誤陽性がユーザのハイライト/アラームを汚す）
- チャット提示と同一ターンで本ファイルに記録 + path 指定 commit (push はリリース窓に同乗)
- 裁定が下りたら該当セクションを即削除し、内容は正規の記録先 (DR / issue / journal / close_reason) へ反映。本ファイルは常に「現在待ち」だけを持つ
- 参照は[]()で提示（リポ内は相対、リポ外はフルパス）
- **初版では背景説明を書かない**。1 項目は「要旨 1 行 + 選択肢 + 理由 1-2 行」で
  完結させる。折りたたみ節に逃がすのも不可 (隠してもコンテキストは食う)。
  求められたら `#### 背景説明` 節に追記する。**この節見出しは消さない** —
  位置が固定されていることで、追記が選択肢の前に来るのを防いでいる
- 選択肢・確認項目は `- [ ] a: …` 形式（チェックボックス + ラベル）で書く。
  Q / C で記法を分けない。回答は「チェックを付ける」でも「XX-Q1a」と言葉で返すでも通る

</details>
